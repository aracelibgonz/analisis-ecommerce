## 🧠 Descripción general

El análisis aborda los siguientes puntos:

1. Limpieza y exploración de datos de ventas online.  
2. Análisis de comportamiento de compra según género y nivel de ingresos.  
3. Visualización de patrones de consumo y métricas clave de performance.  
4. Conclusiones sobre tendencias y oportunidades de mejora.
